# Screenshots - Fingerspot Dashboard

## Cara Mengambil Screenshot

1. Buka aplikasi di browser: `https://fingerspot-eight.vercel.app`
2. Login dengan:
   - Email: `admin@fingerspot.com`
   - Password: `fingerspot123`
3. Ambil screenshot untuk setiap halaman berikut:

## Halaman yang Perlu di-Screenshot

### 1. Login Page
- URL: `/login`
- Tampilan form login

### 2. Dashboard Utama
- URL: `/`
- Statistik total logs, users, devices

### 3. Attendance Page
- URL: `/attendance`
- Tabel log absensi dengan filter

### 4. Users Page
- URL: `/users`
- Daftar user terdaftar

### 5. Commands Page
- URL: `/commands`
- API tester / command sender

### 6. API Requests Page
- URL: `/api-requests`
- Log semua API requests

### 7. Webhooks Page
- URL: `/webhooks`
- Log webhook yang diterima

### 8. Documentation Page
- URL: `/docs`
- Dokumentasi API

## Naming Convention

Simpan screenshot dengan nama:
```
01-login.png
02-dashboard.png
03-attendance.png
04-users.png
05-commands.png
06-api-requests.png
07-webhooks.png
08-documentation.png
```

## Tips

- Gunakan browser Chrome/Edge
- Set viewport width ke 1920px untuk konsistensi
- Sembunyikan bookmark bar untuk tampilan bersih
- Gunakan zoom 100%
